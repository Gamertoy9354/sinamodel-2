# SINA model 2: red saree

`RNGPIT_SINA_Saree_Red.vrm` is a VRM 1.0 avatar in a traditional deep maroon-red saree with a thin gold border, a beige-gold blouse and Indian jewellery.

It's a drop-in replacement for the original `RNGPIT_SINA.vrm`. Every humanoid bone name, mesh name (`Face`, `Body`, `Hair`), all 57 face blendshape names (same order), all expressions and all spring bones are identical, so existing three.js / three-vrm code can load it without changes.

## Showcase video

`RNGPIT_SINA_Saree_Showcase.mp4` is a 20-second 1080p render (Blender EEVEE, 24 fps) of the model in a palace courtyard at dusk, with marigold garlands, rangoli, diyas and falling petals. It shows a namaste with a bow, a face close-up, a full orbit, a low detail glide and a closing hero shot.
